# LYRA Music

Welcome to **LYRA**, a beautiful, fast, and feature-rich music player!

This repository automatically syncs with upstream changes, applies custom LYRA rebranding, and builds the APK via GitHub Actions.

## Features
- Fully automated nightly builds
- Ad-free & Popup-free experience
- Modern Material Design UI

## Download
Check the [Releases](../../releases) tab to download the latest automated APK build.
